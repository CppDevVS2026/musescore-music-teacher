# MuseScore Templates

Pre-built score templates that you can open in **MuseScore 3 or 4** and start
composing immediately.

## Mass_SATB_Organ.mscx

A **Mass Ordinary** template scored for SATB choir and organ.

### Movements

| # | Movement | Tempo | Opening text |
|---|----------|-------|--------------|
| I | Kyrie | Adagio ♩ = 66 | Kyrie eleison. Christe eleison. Kyrie eleison. |
| II | Gloria | Allegro ♩ = 120 | Gloria in excelsis Deo… |
| III | Credo | Moderato ♩ = 96 | Credo in unum Deum… |
| IV | Sanctus | Andante ♩ = 72 | Sanctus, Sanctus, Sanctus… |
| V | Agnus Dei | Adagio ♩ = 60 | Agnus Dei, qui tollis peccata mundi… |

### Instrumentation

- **Soprano** (treble clef)
- **Alto** (treble clef)
- **Tenor** (treble-8vb clef)
- **Bass** (bass clef)
- **Organ** (grand staff — treble + bass)

### How to use

1. Open `Mass_SATB_Organ.mscx` in MuseScore.
2. Each movement is separated by a **section break** — MuseScore resets bar
   numbers and reprints key/time signatures automatically.
3. Rehearsal marks label each movement (I. Kyrie, II. Gloria, …).
4. The Latin text for each movement is shown as staff text above the first
   measure — use it as a reference when entering lyrics.
5. All movements start in C major, 4/4. Change keys and meters as your
   composition requires.
6. Each movement has **8 blank measures** — add more with Edit → Add Measures
   or `Ctrl+Shift+Ins` (Insert Measures).

### Customisation ideas

- Change the key signature for individual movements (e.g. Kyrie in C minor,
  Gloria in E♭ major).
- Add a **Pedal** staff below the organ for an independent pedal part.
- Replace the organ with orchestra parts (strings, brass, timpani) for an
  orchestral Mass setting.
- Add **Solo** voice parts above the choir for movements with solo sections.
